# Rencana: CRUD Pengguna (Livewire Volt) — `admin.pengguna.index`

## Konteks
- Komponen sudah dibuat (placeholder) di `resources/views/admin/master-data/pengguna/⚡main-index.blade.php`
  dan route terdaftar: `Route::livewire('/pengguna', 'admin::master-data.pengguna.main-index')`
  → nama route **`admin.pengguna.index`** (grup `admin.` + `master-data.pengguna`). URL:
  `/admin/master-data/pengguna`, sudah dalam middleware `auth`.
- Model `User`: `#[Fillable(name,email,password)]`, cast `password => hashed`, trait `HasRoles`
  (spatie) + `SoftDeletes`.
- Role tersedia (tabel `roles`): `meggi`, `administrator`, `operator`.
- Sidebar `layouts/sidebar.blade.php`: link "Akun Pengguna" masih `href="#"` → harus diarahkan.

## Keputusan (dari user)
- **Otorisasi**: hanya user dengan role `administrator` atau `meggi` yang boleh akses (gate di `mount`).
- **Role form**: single select (1 role), simpan via `syncRoles([$role])`.
- **Hapus**: soft delete (`delete()`), tanpa UI trash/restore.

### 2. Implementasi CRUD di `⚡main-index.blade.php`
Gunakan satu komponen Volt (idiomatik Livewire): list + modal create/edit + hapus via
`wire:confirm`. Import yang diperlukan:
```php
use Livewire\Component;
use Livewire\WithPagination;
use Spatie\Permission\Models\Role;
use Illuminate\Support\Facades\Auth;
use Illuminate\Validation\Rule;

new class extends Component {
    use WithPagination;

    public string $search = '';
    public bool $showModal = false;
    public ?int $editingId = null;
    public string $name = '';
    public string $email = '';
    public string $password = '';
    public string $password_confirmation = '';
    public string $role = '';
    public array $roles = [];

    public function mount(): void {
        abort_unless(Auth::user()->hasAnyRole(['administrator', 'meggi']), 403);
        $this->roles = Role::orderBy('name')->pluck('name')->toArray();
    }

    public function getUsersProperty() {
        return User::query()
            ->when($this->search, fn ($q) => $q->where(fn ($q) => $q
                ->where('name', 'like', "%{$this->search}%")
                ->orWhere('email', 'like', "%{$this->search}%")))
            ->orderBy('name')
            ->paginate(10);
    }

    public function create(): void {
        $this->reset(['editingId','name','email','password','password_confirmation','role']);
        $this->showModal = true;
    }

    public function edit($id): void {
        $u = User::findOrFail($id);
        $this->editingId = $u->id;
        $this->name = $u->name;
        $this->email = $u->email;
        $this->password = '';
        $this->password_confirmation = '';
        $this->role = $u->getRoleNames()->first() ?? '';
        $this->showModal = true;
    }

    public function save(): void {
        $data = $this->validate([
            'name' => ['required','string','max:255'],
            'email' => ['required','email', Rule::unique('users','email')->ignore($this->editingId)],
            'password' => [$this->editingId ? 'nullable' : 'required', 'min:8', 'confirmed'],
            'role' => ['required', Rule::in($this->roles)],
        ]);

        if ($this->editingId) {
            $u = User::findOrFail($this->editingId);
            $u->name = $data['name'];
            $u->email = $data['email'];
            if (! empty($data['password'])) {
                $u->password = $data['password']; // cast hashed
            }
            $u->save();
            $u->syncRoles([$data['role']]);
        } else {
            $u = User::create([
                'name' => $data['name'],
                'email' => $data['email'],
                'password' => $data['password'],
            ]);
            $u->syncRoles([$data['role']]);
        }

        $this->showModal = false;
        $this->reset(['editingId','name','email','password','password_confirmation','role']);
        session()->flash('success', 'Disimpan.');
    }

    public function delete($id): void {
        if ((int) $id === Auth::id()) {
            session()->flash('error', 'Tidak bisa menghapus akun sendiri.');
            return;
        }
        User::findOrFail($id)->delete(); // soft delete
    }

    public function render() {
        return $this->view(); // pakai layout default layouts::app
    }
};
```

Markup (daisyUI 5, konsisten admin):
- Header: judul "Akun Pengguna" + tombol `btn btn-primary` `wire:click="create"`.
- Search: `<input wire:model.live.debounce.300ms="search" ...>` (atau `wire:model.live`).
- Tabel: kolom #, Nama, Email, Role (badge `badge-soft badge-primary`), Dibuat, Aksi
  (Edit `wire:click="edit({{ $u->id }})"`, Hapus
  `wire:click="delete({{ $u->id }})" wire:confirm="Yakin hapus pengguna ini?"`).
  Loop `foreach ($this->users as $u)`; pagination `{{ $this->users->links() }}`.
- Modal: `<div class="modal" :class="showModal && 'modal-open'">` berisi form
  (name, email, password + password_confirmation, role `<select>` diisi `$roles`),
  tombol Simpan `wire:click="save"` (loading) & Batal (`showModal=false`).
- Tampilkan `session('success')`/`session('error')` via `@if(session('success'))` (atau
  `wire:poll`/flash). Opsional: pakai `wire:model` + `@error` untuk tiap field.

Catatan:
- `getUsersProperty()` dipakai sebagai `$this->users` (Livewire convention).
- Jangan hapus diri sendiri (gate di `delete`).
- Password di-cast `hashed` otomatis saat diset pada model.

### 3. Tests — `tests/Feature/UserCrudTest.php` (Pest)
Buat role dulu di tiap test (test DB sqlite fresh, spatie tidak seed role):
`Role::firstOrCreate(['name' => 'administrator']);` (dan `meggi`, `operator`).
- `administrator_can_view_users`: `actingAs($admin)` → `Livewire::test('admin::master-data.pengguna.main-index')` → `assertSee('Akun Pengguna')`.
- `administrator_can_create_user`: isi props (`name`,`email`,`password`,`password_confirmation`,`role`) → `call('save')` → `assertDatabaseHas('users', ['email'=>...])` + cek role via `User::where(...)->first()->hasRole('operator')`.
- `administrator_can_edit_user`: `edit($id)` → ubah `name` → `save` → `assertDatabaseHas`.
- `administrator_can_soft_delete_user`: `delete($id)` → `assertSoftDeleted('users', ['id'=>$id])`.
- `non_admin_cannot_access` (operator): `actingAs($operator)` → `Livewire::test(...)` → `assertForbidden()` (403 dari `abort_unless`).
- `cannot_delete_self`: `actingAs($admin)` → `delete($admin->id)` → user masih ada (tidak soft-deleted).
Nama komponen Volt = `admin::master-data.pengguna.main-index` (double-colon, konsisten `auth::login`).

## Validasi

- Manual: login sebagai `administrator` → buka `/admin/master-data/pengguna` → tambah/edit/
  hapus pengguna; pastikan role tersimpan & assign. Login sebagai `operator` → akses ditolak 403.
- `vendor/bin/pint --format agent` (untuk kebersihan; file Volt berisi PHP).

## Risiko / Catatan
- Nama route adalah `admin.pengguna.index` (bukan `pengguna.index`) → sidebar pakai
  `route('admin.pengguna.index')`.
- Role harus cocok persis: `meggi`, `administrator`, `operator`.
- SoftDeletes: query default sudah mengabaikan trashed; tidak ada UI restore (sesuai pilihan).
- `MainController@logout` sudah diubah user (di luar scope CRUD ini); pastikan tidak bentrok.
- Pastikan `WithPagination` + `pagination_theme` tailwind (sudah di `config/livewire.php`).
